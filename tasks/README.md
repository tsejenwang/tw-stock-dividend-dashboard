# 任務派送索引

## 任務檔案的共同格式
每份任務檔案都包含：目標、背景／現況、範圍（含／不含）、相依任務、驗收標準、技術備註與資料來源、預估工時。

## 派送前必看
- WBS.md 裡列了幾個「尚待確認的開放問題」（除權息資料來源、是否要 git init + 推 GitHub）。這些如果還沒跟需求方確認，04/11 執行到一半可能要回頭調整範圍。
- 風險試算的定義已經確認（定存股買入/期末價 + 配息打平點試算，見任務 06），不是原本 WBS 草案裡「股利穩定度＋波動度」那個猜測版本，派送任務 06/10 時不要照舊版本做。
