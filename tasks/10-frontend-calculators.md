## 目標
一個網頁畫面，包含兩個子功能：(1) 合理價查詢 — 使用者輸入股票代號查該檔的合理/便宜/昂貴價；(2) 風險試算 — 使用者輸入買入價/期末價/配息/持有年數，即時算出報酬率與最低可容忍股價。

## 範圍
包含：

### 合理價查詢（讀任務 05 預先算好的資料，查表）
1. 輸入介面：文字輸入框（代號或名稱），比照 `stock_widget.py` 裡「輸入代號或中文名稱新增股票」的搜尋體驗（`_search_tw_by_name` 邏輯：關鍵字包含比對，多筆符合時列出讓使用者選）；名稱對照表可以從任務 02 的完整清單資料取得，不需要額外抓取。
2. 查詢結果顯示合理價／便宜價／昂貴價（任務 05 資料），附上近 5 年平均現金股利、樣本年數。
3. 查無資料（樣本不足）要有明確提示，不是顯示空白或錯誤的數字。
4. 這部分是**查詢工具**，讀取任務 05 預先算好的 JSON，用代號當 key 查表，前端不需要自己算數學。
5. 放上任務 05 背景裡需求方提供的操作教學文案（「便宜價時買進，合理價時持有，昂貴價時賣出…選擇股票時，以最近五年現金股利持續成長或保持平穩者為佳，避開現金股利大起大落的股票。」），當作這個功能的說明區塊。

### 風險試算（任務 06 定義的公式，前端即時互動計算，不是查表）
1. 表單四個輸入欄位：買入股價、期末股價、今年配息、持有年數。
2. 買入股價、今年配息預設帶入使用者剛剛查詢（或另外選取）的股票在任務 02 資料裡的「目前股價」「今年配息」，其餘欄位由使用者填寫；所有欄位都可自由覆寫做情境模擬。
3. 即時（不用按送出，輸入變動就重新計算，或至少有明確的「試算」按鈕）顯示：投資報酬率、最低可容忍股價（打平價）、可容忍下跌金額與百分比 — 公式見 [`06-risk-calculation.md`](06-risk-calculation.md)。
4. 輸入驗證：買入股價/持有年數需為正數，配息不得為負，不合法輸入要有清楚錯誤訊息，不能讓頁面算出 NaN/Infinity 還顯示出來。
5. 配息為 0 時要有「沒有配息緩衝、無安全邊際」的提示文案。

### 共同事項
1. 兩者都要有清楚的免責聲明（「僅供參考的粗略估算，不是投資建議」）。
2. 沿用任務 08 建立的整體視覺風格與導覽列。
3. RWD 手機版排版。

不包含：
- 合理價計算邏輯本身（任務 05）
- 風險試算公式本身（任務 06，這裡只是把公式接上 UI）

## 驗收標準
- [ ] 合理價查詢：輸入已知有資料的股票代號能查到正確結果，且 便宜價(×16) < 合理價(×20) < 昂貴價(×32) 的倍數關係成立
- [ ] 合理價查詢：輸入資料不足或不存在的代號有清楚提示，不會讓頁面壞掉
- [ ] 風險試算：用任務 06 驗收時的手算範例（買入 50、期末 45、配息 2、持有 3 年 → 報酬率 2%、打平價 44）在畫面上輸入同樣數字，結果要一致
- [ ] 風險試算：不合法輸入（負數、0 買入價）有清楚錯誤提示
- [ ] 手機尺寸排版正常

## 技術備註
- 合理價查詢與風險試算可以合併在同一個頁面（例如查完合理價後同一畫面下方接風險試算表單並帶入預設值），或分成兩個子頁籤，UI 細節由執行者判斷即可，不用另外確認。
- 跟任務 08、09 一樣維持純靜態 HTML/CSS/JS；風險試算直接呼叫任務 06 定義的 JS 函式即可，不需要額外的後端或 JSON。
