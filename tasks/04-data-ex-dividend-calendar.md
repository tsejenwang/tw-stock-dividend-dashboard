## 目標
產出「近期除權除息日程表」JSON，讓前端能列出即將除權息（或近期已除權息）的股票清單與日期。

## 背景／現況
這是六大功能裡目前**唯一還沒有任何現成程式碼可以參考**的項目 — `get_data.py` 和 `stock_widget.py` 都沒有處理過除權除息日程。第一步必須先做資料來源研究，不能直接開始寫抓取程式。

## 範圍
### 第一步：資料來源研究（務必先做，且務必實際驗證，不要用猜測的 API 路徑）
1. 到 TWSE 開放資料平台（`openapi.twse.com.tw`）瀏覽資料集目錄，找「除權除息預告」或類似名稱的資料集，記錄實際的 API 路徑、回傳格式、欄位名稱。
2. 到 TPEx 開放資料平台（`openapi.tpex.org.tw`）找上櫃股票的對應資料集。
3. 確認資料內容：通常會包含股票代號、名稱、除權/除息日、現金股利、股票股利、最後過戶日、停止過戶期間等欄位 — 實際欄位要以查到的 API 回傳為準。
4. 把找到的來源、路徑、欄位對照記錄下來（更新回 `WBS.md` 的開放問題，並留在這份任務檔案或 commit message 裡）。

### 第二步：實作抓取
1. 依研究結果寫抓取腳本，合併上市＋上櫃的除權息日程。
2. 統一欄位命名（建議：`code`、`name`、`market`、`ex_date`（除權/息日）、`cash_dividend`、`stock_dividend`、`last_trade_date`（最後買進日，如果來源有給的話））。
3. 依日期排序，區分「即將到來」與「近期已發生」（例如前後各 30–60 天，實際範圍看資料來源能查到多遠）。
4. 邊界情況：同一檔股票同時有除權（股票股利）與除息（現金股利）的情況、資料還沒公布的股票。

不包含：
- 前端呈現方式（任務 09）
- 排程自動化（任務 07）

## 驗收標準
- [ ] 有明確記錄下實際採用的 API 來源與欄位對照表
- [ ] 本機執行後能產出近期（例如未來 60 天內）的除權息日程 JSON
- [ ] 抽查 2–3 檔近期真的有除權息的股票，日期與股利金額跟公開資訊觀測站或看盤軟體對得起來
- [ ] 上市與上櫃股票都有涵蓋（或明確記錄若其中一邊查不到資料源的限制）

## 技術備註
- 如果研究後發現 TWSE/TPEx 開放資料都沒有現成的除權息預告資料集，退而求其次的選項：公開資訊觀測站（MOPS）通常有相關公告查詢頁面，但要注意是否有結構化資料（HTML 表格 vs JSON API），以及是否允許程式化存取（留意使用條款）。這種情況要先回報，不要直接刮 HTML。
- 這是全案風險最高的任務（資料來源不確定），如果研究後發現行不通，及早回報以便調整範圍或找替代方案，比悶著頭硬做更重要。
