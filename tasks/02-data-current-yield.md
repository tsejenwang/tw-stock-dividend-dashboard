## 目標
產出一份完整、乾淨的「全市場（上市＋上櫃）當年度殖利率排行」JSON，供前端顯示 Top 20，且欄位足夠讓其他任務（合理價、風險試算）重複使用。

## 背景／現況
`get_data.py` 已經有一版：用 TWSE OpenAPI `BWIBHT_ALL` 抓當年度殖利率，取前 50 名存成 `data.json`。這份可以當起點，但有幾個限制要處理：
- 只有 TWSE（上市），沒有 TPEx（上櫃）。
- 只有代號、名稱、殖利率三欄，沒有現金股利、股價、產業別等排行頁可能會用到的欄位。
- 沒有錯誤處理／重試機制（可參考 `c:\stock\stock_widget.py` 的 `http_get()` 重試邏輯）。

## 範圍
包含：
1. 擴充抓取邏輯涵蓋上櫃股票（TPEx 開放資料，網域 `openapi.tpex.org.tw`，需要先實際查證對應資料集的路徑與欄位名稱，不要用猜的）。
2. 合併上市＋上櫃資料，統一欄位命名（建議：`code`、`name`、`market`（tse/otc）、`yield`、`cash_dividend`、`close_price`、`industry`（如果來源有給的話））。
3. 依殖利率排序，輸出：
   - Top 20（給排行頁直接用）
   - 完整全市場清單（給任務 05/06 查詢合理價/風險用，不用每個任務重抓一次）
4. 資料裡標註「資料日期」（TWSE/TPEx 回傳的是哪一天的收盤資料）。
5. 加上 `c:\stock\stock_widget.py` 裡 `http_get()` 那種重試機制，避免偶發性斷線讓整個排程失敗。
6. 邊界情況處理：殖利率為 0、負值、缺值的股票（例如今年還沒配息）該怎麼呈現，建議直接排除在排行榜之外但保留在完整清單裡。

不包含：
- 5年/10年歷史平均（任務 03）
- 除權息日程（任務 04）
- 排程自動化（任務 07，這裡先做到「手動執行腳本能產生正確 JSON」就好）

## 驗收標準
- [ ] 本機執行腳本後，產出的 JSON 裡 Top 20 筆數正確、殖利率由高到低排序
- [ ] 上市與上櫃股票都有出現在完整清單裡
- [ ] 資料裡有清楚的日期戳記
- [ ] 用瀏覽器或 `python -m json.tool` 檢查 JSON 格式正確
- [ ] 對照 TWSE/TPEx 官網或看盤軟體，抽查 3–5 檔股票的殖利率數字是否合理

## 技術備註／資料來源
- TWSE：`openapi.twse.com.tw`（既有 `get_data.py` 用的 `BWIBHT_ALL`，繼續沿用）
- TPEx：`openapi.tpex.org.tw`，正確資料集路徑需要先上去查證（TPEx 開放資料平台有網頁可以瀏覽所有資料集，不要用猜測的 URL）
- 參考 `c:\stock\stock_widget.py` 的 `http_get()` 重試邏輯與 `HEADERS`（User-Agent）設定
