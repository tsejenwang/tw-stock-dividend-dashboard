## 目標
一個網頁畫面，能切換看「當年殖利率」「5年平均殖利率」「10年平均殖利率」三種 Top 20 排行榜，手機瀏覽器打開也要能正常閱讀。

## 背景／現況
`index.html` 已經有一版陽春的表格（用 Bootstrap 5 + `fetch` 讀 `data.json`），但目前檔案裡混雜了兩份重疊貼上的 HTML（第 43–93 行是誤貼進去的完整頁面片段），這個任務要**整個重寫**，不是修修補補。

## 範圍
包含：
1. 清理掉 `index.html` 裡重複的 HTML 片段，重新設計版面。
2. 三個排行榜用分頁籤（tab）或分段選單切換，共用同一個表格元件（欄位：排名、代號、名稱、殖利率%，可以加上現金股利、市場別 tse/otc 如果任務 02/03 資料有提供）。
3. 讀取任務 02（`data/current_yield_top20.json` 之類）與任務 03（5年/10年榜）產出的 JSON，欄位命名要跟這兩個任務約定好的格式一致。
4. RWD：手機（小螢幕）表格要能捲動或改用卡片式版面，不要出現橫向被切掉看不到的欄位。
5. 顯示資料日期（讓使用者知道「這是幾號的資料」，避免誤以為是即時報價）。
6. 沿用 `index.html` 現有的視覺風格（深藍 header + Bootstrap 卡片），维持整個站台一致的設計語言，之後任務 09/10 也要沿用同一套風格。

不包含：
- 除權息日程表頁面（任務 09）
- 合理價/風險試算工具頁面（任務 10）
- 實際部署上線（任務 11）

## 驗收標準
- [ ] 本機直接用瀏覽器開啟 `index.html`（或本機簡易伺服器），三個排行榜都能正確切換顯示，資料筆數剛好 20 筆、排序正確
- [ ] 用瀏覽器開發者工具切換成手機尺寸（例如 iPhone 尺寸）檢查排版不跑版、文字不會被切斷
- [ ] `data.json` 抓取失敗時（例如檔案不存在）頁面要有合理的錯誤提示，不是空白一片或 JS console 報錯讓使用者看到當機的樣子

## 技術備註
- 保持純靜態（HTML/CSS/JS + `fetch`），不需要額外的前端框架（React/Vue）— 這個規模的頁面用 vanilla JS 就足夠，符合 WBS 的「靜態網頁」架構決策，也避免增加建置流程的複雜度。
- 導覽列（nav）要預留位置給任務 09、10 的頁面連結，讓整個站台之後串得起來（任務 11 會做最後的整合檢查）。
