## 目標
提供「定存股風險試算」的計算邏輯：使用者輸入買入股價、期末股價、今年配息、持有年數，算出投資報酬率；並算出報酬率為 0 時的「最低可容忍股價」，讓使用者一眼看出這檔股票靠配息能撐住多少下跌。

> 這個定義是需求方明確給的規格（附圖：「定存股：風險說明」畫面），**取代** `WBS.md` 早期草案裡「股利穩定度＋殖利率波動度」那個先射箭再畫靶的猜測版本。

## 背景／現況
四個輸入欄位：
- **買入股價**：欲買入股票的目前價格
- **期末股價**：預估當期末股票賣出時的價格（使用者可以自由調整，用來找打平點）
- **今年配息**：欲買入股票今年每股配息金額
- **持有年數**：預計持有股票年數

風險試算的核心概念：股票會漲會跌，期末股價往下跌會拖累報酬率，但因為定存股每年都有配息，不一定會虧損。試算的目的是找出「期末股價跌到多少，投資報酬率剛好等於 0（打平）」，這個價格以下才真的開始虧損。殖利率越高、持有年數越長，可以容忍的下跌空間就越大。

## 範圍
包含：
1. 實作核心公式（純數學，不需要抓取任何新資料，也不需要對全市場批次計算或存成 JSON — 這點跟任務 05 的「預先算好查表」不同，是使用者互動當下即時算的）：
   - `投資報酬率(%) = (期末股價 − 買入股價 + 今年配息 × 持有年數) ÷ 買入股價 × 100`
   - `最低可容忍股價（打平價） = 買入股價 − 今年配息 × 持有年數`
   - `可容忍下跌金額 = 今年配息 × 持有年數`（= 買入股價 − 打平價）
   - `可容忍下跌百分比(%) = 可容忍下跌金額 ÷ 買入股價 × 100`
2. 輸入驗證：買入股價必須 > 0；持有年數必須為正數；今年配息不得為負數（可以是 0，代表今年沒配息，此時打平價等於買入股價，沒有安全邊際，UI 要清楚提示這種情況）。
3. 預設值：買入股價、今年配息這兩欄，預設帶入任務 02 資料裡該檔股票的「目前股價」與「今年現金股利」，使用者不用手動查資料就能先看到一組合理的結果，但仍可自行覆寫做情境模擬（例如假設配息成長或衰退）。
4. 免責聲明比照任務 05：僅供參考的粗略試算，不是投資建議。

不包含：
- 原先草案裡「用近 5–10 年歷史股利穩定度算風險等級」的分析（如果之後還想額外做這個當作「股利穩定度風險」的加值功能，可以另開新任務，跟這個定存股打平點試算並存，不互相取代）
- 前端輸入表單與結果呈現的 UI 本身（併入任務 10 一起做）

## 驗收標準
- [ ] 用幾組手算過的數字驗證公式實作正確，例如：買入 50、期末 45、配息 2、持有 3 年 → 報酬率 = (45−50+6)/50×100 = 2%，打平價 = 50−6 = 44
- [ ] 今年配息 = 0 時，打平價等於買入股價，且結果畫面/回傳值有清楚標示「沒有配息緩衝，无安全邊際」
- [ ] 買入股價 ≤ 0 或持有年數 ≤ 0 時，有明確的輸入驗證錯誤，不會算出 Infinity / NaN 或誤導的數字

## 技術備註
- 因為是純公式、不需要批次資料，建議直接寫成一個小型、可重用的 JS 函式（例如 `calcRiskBreakeven({buyPrice, endPrice, dividend, years})`），在任務 10 的前端頁面裡直接呼叫，不需要獨立的 Python 腳本或額外的 JSON 產出物。
- 依賴任務 02 只是為了拿「目前股價」「今年配息」當輸入框預設值，不是必要依賴 — 就算任務 02 的資料格式還沒定案，這個公式本身也可以先獨立寫好並測試。
